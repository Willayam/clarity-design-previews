Finish your video: state cleanup

Every state of the recorder's finish screen, before and after, rendered from a scripted offline take. The account and video are mock data.

Rules the after column follows.

  • The header shows the title only. Problems appear in one place, as red rows above the video, and a row carries a Retry when there is something to retry.
  • Each button keeps one label. A spinner carries the wait. "Copied" is the one swap.
  • A button is disabled when pressing it could only fail.
  • The dock is a rounded rectangle, so its buttons have an 8px radius inside a 10px outline. Only the round play button is a circle.
  • Trim and Edit Preview both commit with "Done".

Dock at rest

Trim and Edit Preview were pill buttons inside a pill outline. They now keep the 8px button radius inside a 10px outline, which matches the dock's own rounded rectangle. The play button stays round.

Dock in trim mode

The commit button said "Trim", the same word as the button that opens trim mode. It now says "Done", like Edit Preview. The outline is a rounded rectangle on phone too, where it used to become a pill.

Just stopped, link on its way

Copy link used to read "Preparing link…". It now always reads "Copy link", with a spinner while it waits. Open page stays disabled until the take's record exists, because pressing it earlier could only fail.

Ready

"Changes saved" is gone from the header. It appeared before you had changed anything, because it was reporting the upload's own first save.

Just copied

Unchanged. "Copied" is the one label swap left, because it reports a finished result.

Share link failed

The button used to turn into "Retry link" while a red row said the same thing. Now the row carries the Retry, the same pattern as a failed upload, and the button keeps its name.

Share link failed, then a save landed

Bug fixed. A later save used to wipe the red row, which left "Retry link" with no explanation. The row now comes from the link failure itself, so it stays.

Opening the page

The button used to say "Opening…" while the header said "Saving changes…". Now there is one signal, a spinner on Open page.

Upload failed

Two red rows used to report one failure, and Copy link claimed "Preparing link…" while nothing was preparing. Now there is one row with Retry, and both actions are disabled with no spinner.

Open page pressed during upload

Used to fail with "Unable to open the page." Open page is now disabled until the link is ready.

A background save failed

The header chip said "Couldn't save" and a row said "Unable to save changes." Only the row is left. All error copy now starts with "Couldn't…".

Saving right after upload

The header chip is gone, so this state now looks like Ready.

Save queued behind another

The grey "Changes pending" chip is gone.

Trim mode

Commit reads "Done".

Trim saving

The header chip is gone. Done and Cancel disable while the save runs.

Edit Preview mode

The radius matches the rest of the dock.

Hovering Trim

The hover tint follows the 8px radius instead of a pill.

Share link retry, after only
