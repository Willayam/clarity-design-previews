After

Problem. The outbox interface returns a bare HTTP number, so permanence is nobody's decision. Two rows have retried 3,000+ times since 10 Sep. ready_unpublished has the same shape, and a failed kick leaves the row at the head of a 50-row sweep.

Solution. Classify the outcome once, inside the module. Cap attempts. Add a dead state that alerts.

  • lost recordings become visible
  • sweep cannot be starved
  • testable: drive a 409 through delivery
  • same rule for webhooks and metadata writes

Tickets: WIL-3394, 3315, 3362, 3350, 3285, 3318. Four areas, one missing discipline: server-side preconditions and terminal states.
