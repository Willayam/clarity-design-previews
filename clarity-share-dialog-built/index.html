Share dialog: settings rows, a status band and one action (F1b, Cascade)

PR #1457

Round two hid Unpublish and the password under "More options", and William found it more complicated. He picked prototype F1b and the Cascade motion: a rep sees what visitors see in one coloured band, the next step in one full-width button, and turning the link off is a labelled choice ("Who can open it: No one") that asks first, the access pattern Google Docs and Figma use. The password field protects only once saved, which is how the router applies it, and the eye toggle is the one from sign-in.

What changes (11)
  • Status box with an Unpublish button -> a band above the button: green "Live / Published 2h ago.", yellow "Live / Visitors see the version from 2h ago.", grey "Off / The link is off. Publish to bring it back.", grey "Not published / Nobody can open it until you publish."
  • One full-width primary per stage: Publish (never published), Copy link (live), Publish changes (live with edits), Publish (off).
  • Link chip with an open-arrow and a copy icon -> the URL itself is the underlined link, plus one copy icon only while live; while off the address is dimmed text; never-published pages have no link row because the router mints the address on first publish.
  • Unpublish button -> "Who can open it" select (Anyone with the link / No one, "Turns the link off"), hidden before first publish, a static "No one" while off. No one asks "Turn the link off?" with "People you sent it to will see that the page is unavailable. Your edits stay saved. Publish turns the same link back on with your latest edits."
  • Password: the switch only opens the field; Save protects. Help line before Save on a live page: "Press Save to use this password. Everyone you already sent the link to will need it."; after: "Saved. Everyone with the link needs it now.". The Show/Hide is the sign-in eye toggle (PasswordToggle moved to components/).
  • "Draft version n · Published version m" line removed.
  • Copied shows only after the clipboard accepts; a refusal says "Couldn't copy. Select the link and copy it."
  • Cascade motion: changed parts in reading order 45ms apart, 170ms ease-out fade with a 4px rise, band 260ms with one ring on going live, bottom-up on turn off, heights animate, the dialog grows away from the pressed control, reduced motion drops movement.
  • Dialog 512px -> 420px wide; title size text-xl -> the dialog default.
  • SelectTrigger is flat inside dialogs and menus; SelectValue no longer capitalises (the Contacts phone-type values are already capitalised).
  • New data-analytics-id: share_open_link, share_copy_icon, share_access, share_access_anyone, share_access_no_one, share_password_toggle, share_password_reveal, share_password_save, share_publish, share_copy_link, share_turn_off, share_turn_off_cancel, auth_password_reveal, reset_password_reveal. Round two's share_more_options and share_unpublish* are gone with their controls.
