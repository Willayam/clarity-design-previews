What changed after D8

D8 published report

D8's three fact-preserving rewrites chose pages_generate in replace mode. That maps to create mode and omits the current document. Its translation turns also used replacement generation. In update mode the generator does receive the current document, minus non-content extras. Replacement omits that context. In D8 translation repetition 1, pages_generate reported revision 4 while the stored page still had English headings and body text. The merge can rescue omitted blocks with their old copy. Raw generation output was not logged, so that receipt cannot distinguish a model omission from the preservation path. Another translation created a different page instead of editing the current one. The shared prompt and tool description now direct wording-only changes, translation and shortening through pages_edit after a full document read, with a read after changes to check facts and language. The repeated question already appeared twice inside a single model step, so it came from the model, not a UI fold or retry. No output dedupe was added.

A second bug lost pasted notes after a clarification. Older source messages became a reference, while the runner expanded only the current turn's pasted sources. A regression test first passed the literal @source:1 to generation, then passed the original notes after the fix. The most recent pasted notes now survive clarification; newer pasted notes replace the active reference. The L1 audience rule and L3 aggregate activity tools are included in this code head.
