What else happens

  • clarity.video/todd opens the page, and the short link stays in the browser bar. The old link keeps working, so nothing Todd already sent breaks.
  • A link Todd used stays his. If he changes it again, the old one keeps opening the page. If he deletes the page, it shows his name instead of a 404.
  • Dashes don't count when names are compared, so nobody can take todd-smith next to toddsmith. A listener who skips the dash still lands on the page.
  • Each account can hold about five custom links. The limit only shows up when Todd reaches it.
  • This version leaves out suggestions, the spoken version and a separate stats split. Visits to the page already count, whichever link brought them.
