Each task is scored from the account's state afterwards, not from what the agent said. Publish, share and delete are approved by the harness acting as the account owner. What changed between the runs

Before. Main's connector: nine operations, reads plus page draft edits.

After round 1. 34 operations from one registry, shared by the MCP connector and the new clarity CLI. Typed schemas every host can read, refusals that say what failed and how to fix it, uploads, folders, video edits, page creation and AI drafts, settings, contacts, and publish, share and delete through the owner's approval.

After round 2. Fixes from round 1's failed cells and agent feedback: one approval for several video edits, folder deletes that say which pages move, replays that notice a deleted record, allowed values in refusals, an edit help operation, changed blocks in every edit answer, and a CLI whose help works everywhere.

How to read the numbers

Seats are fresh agents: Claude (fable, opus, sonnet) and Codex (gpt-6-sol, gpt-6-astra) through the MCP connector, and two seats that only had a shell and the CLI. A failed call is a tool call the server refused. Total seconds rose in round 2 because agents now wait up to 45 seconds for the owner's approval in one call instead of polling; the harness approves after the agent's turn ends, so those waits run to the end.
