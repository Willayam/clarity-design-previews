Which rules could a switch replace?

None is proven unnecessary. The clean 10-run poisoned-summary sample and 20 typed summaries make repeated prompt patches aimed at eager summary generation a lower priority for GPT-5.2. They do not justify removing the final “When the rep asks for a page” condition. That is the task contract, and this run kept it enabled.

Keep the since-D12 reader/source selection checks and pivot/replacement prompt lines: wrong accepted inputs and false refusals remain. Keep the stop-writes-after-an-approval-card guard, the one-new-page limit and the empty/question-only generation guard: this study did not disable them, so it cannot measure whether GPT-5.2 replaces them. Keep password masking/completion notes and unpublish approval semantics: g4's ten password changes are encouraging but g18/g19 were outside D18. Keep the private-fact exclusion and no-narration lines: both still fail. G3's failures and missing g7 give no basis to remove the follow-up-drafting or build-from-supplied-material guidance. No rules or prompt lines were removed.

What this says about reasoning

One existing candidate row was used: openai/gpt-5.2-chat-low, snapshot gpt-5.2-2025-12-11. It supports Chat Completions function calling with low reasoning, the lowest above-none setting on that row. Both the app and the forced probe used the clarity-preview gateway with the existing preview key; payload logging stayed off. No catalog row, Responses adapter or product default was added.

Current OpenAI documentation requires Responses for GPT-6-family tools with reasoning. GPT-6 Sol and Luna permit Chat Completions tools only at none; Astra and 6.1 Sol/Terra require Responses for tools. The preview key returned 401 on the earlier Responses probes. No GPT-6 reasoning quality arm ran here. This result tells us nothing about whether those models would clear the gate if that route worked. See the GPT-5.2 model documentation and the earlier D9 route evidence.

The model and reasoning setting changed together. The shared page generator stayed on Luna low. GPT-5.2's improvement therefore cannot isolate reasoning effort, and its direct-edit leaks show that changing only the chat model does not solve page privacy. The remaining failures include model judgment, host reader matching and an unmeasured provider-failure cause. They cannot all be assigned to one of those from this run.
