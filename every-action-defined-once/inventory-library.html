Non-obvious things

  • The Library has no separate Worker or database. createLibrary runs in the frontend router process, workers/workspace-tree/src/library.ts:47-60. PAGE_LIBRARY_DB and AUTH_DB name the same D1 database per ARCHITECTURE.md.
  • The router transforms successful Library JSON after the Library responds. It signs image and document access URLs and adds stats counts in workers/frontend-router/src/library-media.ts:33-81,97-167. A single output schema inside the Library would not describe the final browser response without that adapter.
  • A read can write. The take, speech and listing paths can settle Mux facts; the speech GET can also start due jobs. These effects are explicit at mux-video-routes.ts:68-75, video-speech-routes.ts:48-85 and index.ts:333-339.
  • Uploads are multi-step. The R2 RPC grants a presigned PUT, then the browser writes bytes directly to R2, r2-media/src/index.ts:547-619. Mux direct uploads likewise grant a Mux ticket, while asset readiness arrives later by webhook or read repair, mux-video-routes.ts:83-149,221-306.
  • Mux and Stripe have different idempotency models. Mux uses monotonic lifecycle writes and provider redelivery on contention, mux-webhook.ts:30-42. Stripe captures an immutable event receipt before acknowledgment, then claims and retries it from D1, stripe-billing.ts:576-625, provider-event-inbox.ts:78-141.
  • Mux unshare deliberately allows at most one external copy POST per recorded job. It persists posted before the call and leaves an uncertain result for an operator rather than issuing an automatic second POST, mux-unshare-jobs.ts:166-189.
  • r2-media media reads stream bytes, handle ranges, conditional GETs, signatures and cache fills, r2-media/src/index.ts:136-160,176-260. These are materially different response and effect shapes from JSON CRUD actions.
  • I found no Convex directory, convex.json, or textual convex reference in the tracked source search (rg --files and rg -n over this checkout, excluding lock and snapshot files). No Convex function on main was found.
