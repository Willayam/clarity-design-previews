Activity facts row: options

Five ways to set the facts row in the Activity modal (PR #1450). Each option shows the page modal and the video modal at desktop width and as the phone sheet. Every option fixes the same baseline problems in the current row: tabular numbers, one value size, one label size, equal columns, and a planned wrap on the phone instead of flex-wrap. Mock data throughout.

Pick: B, one band with dividers. It gives the row the highlight William asked for with one surface instead of four, and that surface is the same slate-100 the table already stripes with, so nothing new enters the modal. The jaggedness itself comes from flex-wrap and unequal columns, and B's equal columns, hairlines and tabular numbers remove it at desktop and phone width alike.
