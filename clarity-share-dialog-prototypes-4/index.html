Share dialog: what Framer, Figma and Google Docs do

Every dialog is live. Pick a state above each one, then press the controls inside. Nothing talks to a server. The first three copy one app each as closely as Clarity's needs allow (one page, one public link, publish and publish changes, unpublish, optional password). The last three are round three's band menu, access row and header menu, fixed with this round's lessons. Where an app's pattern overrides an earlier decision (password as its own row, the band next to the primary, Copy link as the primary while current) the card says what differs and why.

Lessons applied to every card: one icon in the link row, never the open arrow next to the copy icon; a clickable URL is underlined; no "Link on" switch; nothing red at rest; no separate off section; every confirm says the link stops working and that Publish turns the same link back on.

Patterns that repeat. One primary whose label follows the state (Framer's Publish then Update, Figma Sites' Publish). Site builders show when the site was last published; doc tools that sync edits show nothing. Turning the site off lives away from the primary, either in settings (Framer, Figma Sites, Webflow) or as a secondary control in the same panel (Notion, Google). Copy link sits apart from the primary (Docs bottom-left, Figma text button, Notion icon on the URL). Password is a settings toggle in every builder that has one; none puts it in the publish popover.

What every card shares

  • The link row has the URL and at most one icon. Either the URL is plain and one arrow opens it, or the URL is underlined and opens itself and one copy icon sits beside it. Never both icons. Off or never published, the row dims and the copy icon disables.
  • Password protected is a switch row with a lock, and the password input under it when on. The Framer card keeps it behind the gear, as Framer does.
  • Unpublish is never red at rest, never a text link, and always asks first. The confirm says the link stops working for everyone you sent it to, and that Publish turns the same link back on.
  • Turned off is a state of the same controls (the band word, the access select, the status field), not a separate captioned section.
