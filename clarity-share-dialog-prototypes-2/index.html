Share dialog: six takes on "link first"

Every dialog is live. Pick a state above each one, then press the buttons inside. Nothing talks to a server. All six keep the same bones from your notes: the link row with its open and copy icons, a green "Live", amber when visitors see an older version, Publish in the bottom right, and a real Unpublish button that asks before the link stops working. They differ only in where the status sits, how amber is drawn, how Unpublish looks, and where the password lives. Round one's option 3 is at the end for comparison.

What stays fixed in all six

  • The link row is the original chip: URL, open-in-new-tab arrow, copy icon. Off or never published, the chip dims and the copy icon disables.
  • "Live" with a green dot when the page is live and nothing is pending.
  • Live with unpublished changes turns amber and says "Visitors see the version from 2h ago". Clarity knows changes exist, not how many, so there is no count.
  • Publish or Publish changes is the only primary button and sits bottom right. When everything is live the slot reads "Up to date".
  • Unpublish is a full-size button labelled "Unpublish", never red text alone, placed away from Publish, and the confirm says the link stops working.
